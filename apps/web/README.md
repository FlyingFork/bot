## Deployment Environment

For Better Auth behind a VPS reverse proxy, `BETTER_AUTH_URL` and
`BETTER_AUTH_TRUSTED_ORIGINS` must use the public browser-facing origin, not
the internal Node.js port.

```bash
BETTER_AUTH_URL=https://example.com
BETTER_AUTH_TRUSTED_ORIGINS=https://example.com
```

If the app is reachable from multiple public origins, separate them with
commas:

```bash
BETTER_AUTH_TRUSTED_ORIGINS=https://example.com,https://www.example.com
```

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
